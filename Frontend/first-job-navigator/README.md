Each team member contributes has responsibilities are distributed based on technical focus areas related to the backend team's requirements.

React and Typescript are a good fit for our frontend because the app will be made up of several interactive tools. Features like the Salary Simulator, budget planner, pension projection, learning hub and move out readiness checker all require reusable UI components, live updates and state handling which is clear, so react allows our features such as the salary calculator and budgeting tools to be built as reusable content while Typescript will help prevent runtime crashes and data leaks.
